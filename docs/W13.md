# The workshop

This repo is the tool. The workshop is a separate thing that uses it, and its source of truth is the residency repo:
`~/Documents/work/tpl/applied_ai_2026/events/W13-personal-library-app/W13.md`.

## The boundary

The resident's rule from the last project of this kind: the public repo describes the tool, the event file describes the
session, and neither describes the other's arrangements. Applied here, the split is by subject rather than by name: this
repo names the library where the adapter needs it, because the adapter is the library (data sources, URLs, vocabulary),
and says nothing about the workshop's dates, room, participants, or teaching plan. The event file points here for the
tool and never restates the architecture.

## What the workshop needs from this repo

- A **starter** a beginner can open on a library machine: the shelf, ratings, practice mode and the example mode,
  working from the first second, with nothing to install. The events list is a P1 task here.
- A **practice shelf** that fills with example books and clears in one click, so the machine can be tested and wiped
  without touching anything real.
- A **brief** the room's agent can follow: one page, the loop, the ids-only rule for anything a model chooses.
- A **menu of modes** as buildable briefs (`docs/modes/`), with reference builds of three of them for the projector,
  because the room chooses and the show-and-tell compares mechanisms.

## What the tool does not need from the workshop

Participant data, accounts, or any tracking of what the room did. The workshop's transcript collection is the residency's
own machinery and stays out of this repo.

## Still open between the two

- Whether the workshop's starter is this repo's app with a slice, or a small separate build that shares the data files.
  **Proposed (2026-11-03):** `python3 tools/build.py --starter` makes the folder (the app, the contract, the mode briefs,
  the check tool), and the kit adds its own brief and session files on top. Neither repo holds the other's files. The
  first run (Nov 7) keeps the residency starter; the second run (Nov 26) is the first that could use this one.
- Whether the hosted copy lives at a subdomain of the residency's domain. That is the library's answer to give, not
  ours, and `docs/DECISIONS.md` D11 records it as open.
